One sentence of horror, under 200 characters, written to `/output/entry.txt`:
a nightly ritual, a second plate, and a whispered invitation — the scare is
what the reader realises is sitting at the table, and that it comes back
every night. The line won a local pairwise tournament of 14 fresh candidates
scored on the judge's own rubric (fright, vivid, original, crafted).

## Run it

```sh
python3 main.py
```

The program is deterministic and standard-library only. It writes the entry
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and checks
the 1–200 character gate itself before writing.
